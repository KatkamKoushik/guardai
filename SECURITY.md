# Security Policy

I take the security of GuardAI seriously. As a cybersecurity and threat intelligence platform, maintaining high standards of integrity, confidentiality, and operational security across the codebase and data pipelines is paramount.

## Supported Versions

I actively maintain and provide security updates for the following versions of GuardAI:

| Version | Supported |
| ------- | --------- |
| 1.0.x   | Yes       |
| < 1.0   | No        |

## Reporting a Vulnerability

If you discover a security vulnerability within GuardAI, please do not open a public issue on GitHub. Instead, follow this responsible disclosure procedure:

1. Send a detailed report to my security email: `koushikkatkam@gmail.com`.
2. Include the following details to help me reproduce and triage the issue efficiently:
   - Type of vulnerability (e.g., SSRF, injection, authentication bypass, data exposure).
   - Step-by-step instructions or proof of concept to reproduce the issue.
   - Affected components, API routes, or dependencies.
   - Potential impact of the vulnerability.
3. Allow me reasonable time to investigate, address, and deploy a fix before any public disclosure.

## Response Commitment

- Acknowledgment: I will acknowledge receipt of your vulnerability report within 48 hours.
- Assessment: I will evaluate the vulnerability and provide an estimated timeline for a patch.
- Remediation: Once resolved, I will publish a security patch and credit the reporter in the release notes, unless anonymity is requested.
